# Версия 1.1.0 — обновления и обратная связь

- Добавлена автоматическая проверка новых версий.
- В настройках появились скачивание, прогресс и установка с перезапуском.
- Перед установкой автоматически создаётся резервная копия данных.
- Добавлена отдельная вкладка «Обратная связь» с необязательным контактом.
- Адрес получателя обратной связи скрыт и хранится только на серверной стороне.

# Версия 1.2.0 — удобные обновления и обратная связь

- Добавлена проверка новых версий прямо в настройках приложения.
- Обновление скачивается с индикатором прогресса и устанавливается после автоматической резервной копии.
- После установки приложение самостоятельно перезапускается.
- Добавлена отдельная вкладка «Обратная связь» для предложений, ошибок и вопросов.
- Получатели обновлений не нуждаются в аккаунте GitHub: достаточно подключения к интернету.
- Сохранены ранее добавленные деньги, мана, классовые и пользовательские способности персонажей.

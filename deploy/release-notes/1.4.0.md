# Версия 1.4.0 — «Тишину навели»

- В левом меню появился отдельный раздел «Тишину навели» с каталогом встроенных мини-игр.
- Добавлены полноценные «Змейка», «Тетрис» и «Сапёр» с клавиатурным управлением.
- Добавлена самостоятельная открытая ретро-арена в стиле классического Doom без закрытых ресурсов оригинальной игры.
- Для каждой игры показываются текущий счёт и лучший результат.
- Рекорды сохраняются на компьютере и не пропадают после перезапуска приложения.
- Во всех играх доступны повторный запуск и пауза.

# Обработчик обратной связи

Этот код разворачивается как Google Apps Script Web App и пересылает сообщения на Gmail. Адрес получателя не хранится в исходниках и не передаётся приложению.

При публикации:

1. Создать проект Apps Script под аккаунтом владельца приложения.
2. Вставить `Code.gs`.
3. В `Project Settings` → `Script Properties` добавить `RECIPIENT_EMAIL` с адресом получателя.
4. Развернуть `Web app`: выполнять от имени владельца, доступ — всем пользователям.
5. Скопировать URL `/exec` в `Distribution:FeedbackEndpoint` производственной сборки.
6. Отправить тестовое сообщение и убедиться, что оно пришло в Gmail.

Никогда не добавляйте `RECIPIENT_EMAIL` в `appsettings.json`, исходники или GitHub. URL обработчика не является полноценным секретом, поэтому обработчик строго ограничивает размер и формат данных; при заметном спаме его следует заменить на endpoint с CAPTCHA/rate limiting.

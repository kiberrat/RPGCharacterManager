# Выпуски, обновления и обратная связь

## Что увидит пользователь

Пользователь один раз запускает `RPGCharacterManager-win-Setup.exe`. Дальше приложение при запуске тихо проверяет GitHub Releases. Если версия новее, появляется уведомление. В `Настройки → Обновления приложения` доступны кнопки проверки, скачивания и установки. Перед установкой создаётся резервная копия, затем приложение закрывается, обновляется и запускается снова.

GitHub-аккаунт пользователю не нужен — только интернет.

## Локальная проверка

```powershell
.\build-release.ps1 -Version 1.1.0 -ReleaseNotes .\deploy\release-notes\1.1.0.md
```

Установщик появится в `releases-local`. Локальная сборка читает обновления из этой же папки и не обращается к GitHub.

## Первая публикация

1. Создать публичный GitHub-репозиторий и загрузить исходники.
2. Развернуть обработчик из `deploy/feedback-google-apps-script`.
3. В GitHub добавить Actions secret `FEEDBACK_ENDPOINT` со ссылкой Apps Script `/exec`.
4. Добавить описание выпуска `deploy/release-notes/<версия>.md`.
5. Запустить workflow `Publish Windows release`, указав версию.

Workflow выполняет все тесты, собирает Setup.exe и пакеты Velopack, затем создаёт GitHub Release. Адрес Gmail не попадает ни в GitHub, ни в EXE: он хранится только в Script Properties проекта Apps Script.

## Важное перед распространением

Тестовый установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение. Для широкого распространения желательно приобрести сертификат подписи кода и передать параметры подписи Velopack.
